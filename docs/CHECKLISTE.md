# Probelauf vor dem Vortrag

Am besten ein paar Tage vorher, auf genau dem Rechner, der vor Ort verwendet wird.

## Dateien

- [ ] HTML-Datei liegt direkt auf dem Rechner (z. B. Desktop), geöffnet in Chrome oder Edge
- [ ] Kopie von HTML und Notfall-PowerPoint auf einem USB-Stick
- [ ] dritte Kopie im eigenen Google Drive (bei Bedarf herunterladen, die Drive-Vorschau zeigt die Seite nicht)
- [ ] Leihgerät der Veranstalter? Vorher klären, ob USB-Stick erlaubt ist und Chrome oder Edge installiert ist

## Probelauf

- [ ] WLAN aus, einmal komplett durchklicken (die Datei braucht kein Internet)
- [ ] Windows+P → „Erweitern“: Präsentation im Vollbild (F) am Bildschirm, Notizenfenster (N) am Laptop
- [ ] Notizenfenster blockiert? Pop-ups für die Datei erlauben
- [ ] Video: läuft es über HDMI, mit Ton falls nötig?
- [ ] Klicker testen, auch nachdem in eine Live-Demo geklickt wurde
- [ ] Kurzfassung (K) einmal an- und ausschalten
- [ ] Energiesparmodus aus, „Nicht stören“ an, Windows-Updates pausieren, Ladekabel dabei

## Vor Ort

- [ ] Bildschirm anstecken, einmal bis zum Video durchdrücken, mit 0 zurück auf die Startseite
- [ ] Notizenfenster offen, Timer startet mit dem ersten Klick (oder „Timer auf 0“)
